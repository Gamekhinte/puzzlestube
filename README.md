# Puzzlestube von screame

Werbefreie Puzzle-Web-App, auf Deutsch und für Senioren gebaut. Läuft komplett im Browser, ohne Server.

- 2D-Puzzles von 36 bis 1000 Teilen, mit eigenen Fotos oder 305 mitgelieferten Familienfotos
- 22 3D-Puzzles mit 36, 112 oder 250 Teilen: echte gescannte Modelle von Poly Haven (CC0, auch kommerziell frei), die App schneidet sie selbst in Teile
- Speichert den Stand von selbst, läuft nach dem ersten Laden offline

## Starten

```bash
npm install
npm run dev
```

Fertige Version: `npm run build`, das Ergebnis liegt in `dist`.

## Bildnachweis

Alle mitgelieferten Fotos sind eigene Aufnahmen der Familie. Alle Rechte vorbehalten, keine Weitergabe ohne Erlaubnis.
